# AI 知识库 · 项目愿景 v1.0

## 要做什么
- 每天抓取 GitHub Trending（20条，只筛选 AI 相关）
- 用 Agent 分析 README 内容
- 输出 Markdown 格式知识条目

## 输出格式
| 字段 | 说明 |
|------|------|
| 标题 | GitHub repo 名称 |
| 简介 | README 前 100 字或 description 字段 |
| 重点整理 | 3-5 点核心功能 |
| 关键字 | 5-10 个标签 |
| 关键问题 | 1-2 句话说明解决的核心问题 |

## 不做什么
- 不处理历史数据（只保留当天内容）

## 边界
- 同一天相似的 AI repo 只保留 1 个

## 验收标准
| 维度 | 指标 |
|------|------|
| 质量 | 所有字段非空、无明显错误 |
| 数量 | 每天成功处理 ≥15 条 |
| 效率 | 单次运行时间 < 5 分钟 |

## 怎么验证
- 每日运行脚本，检查输出文件完整性
- 统计成功处理数量
- 记录运行时长
